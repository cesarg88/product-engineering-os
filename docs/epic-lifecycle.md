# Epic Lifecycle

Every feature in PEOS follows the same lifecycle.

---

## Stage 1 — Product Roadmap

The Epic appears in the Product Roadmap.

Question:

Should we build this?

Owner:

CEO + CTO

Output:

Product Roadmap

---

## Stage 2 — Epic Specification

The problem is fully understood.

Product decisions are made.

No implementation is discussed.

Question:

What are we building?

Owner:

CEO + CTO

Output:

Epic Specification

---

## Stage 3 — Technical Strategy

Architecture decisions.

Interfaces.

Boundaries.

Trade-offs.

Question:

How should this be built?

Owner:

CTO

Output:

Technical Strategy

Architecture documents

ADRs

---

## Stage 4 — Implementation Proposal

The Lead Orchestrator produces an implementation proposal.

No production code is written.

Question:

How should the work be divided?

Owner:

Lead Orchestrator

Output:

Implementation Proposal

Milestones

Implementation plan

---

## Stage 5 — Delivery

Implementation begins.

Specialized agents execute the work.

Question:

Can this be implemented?

Owner:

Lead Orchestrator

Specialized Agents

Output:

Code

Tests

Documentation

Pull Request

---

## Stage 6 — Review

The implementation is reviewed.

Product correctness.

Architecture.

Code quality.

Question:

Should this be merged?

Owner:

CEO

CTO

PR Reviewer

Output:

Approved Pull Request

---

## Stage 7 — Merge

The work becomes part of the product.

Documentation is updated.

Roadmap status changes.

Question:

Is the Epic complete?

Owner:

CEO + CTO

Output:

Merged implementation

Updated roadmap
