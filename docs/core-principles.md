# PEOS Core Principles

These principles govern every project built using PEOS.

---

## 1. Human Decision Authority

Humans own decisions.

AI may propose.

AI never changes product direction autonomously.

---

## 2. Documentation First

Product decisions are documented before implementation begins.

Code is the consequence of approved decisions.

---

## 3. One Horizon at a Time

Only one Development Horizon may be active for a given Epic.

A Horizon must be explicitly completed before the next one begins.

This prevents implementation from racing ahead of product or technical decisions.

---

## 4. Architecture Before Implementation

Implementation follows approved architecture.

Architecture does not emerge during coding.

---

## 5. Review Before Merge

Every change must be reviewed from both:

- Product perspective
- Technical perspective

before it becomes part of the product.
